**Nine.** is a desktop application for property managers and landlords managing up to nine residential rental properties.

**Perfect for:**

- Independent property managers and landlords
- Property owners who self-manage their rentals
- Anyone seeking focused, no-subscription property management software

## System Requirements

|             | Minimum                       | Recommended     |
| ----------- | ----------------------------- | --------------- |
| **OS**      | Linux or Windows 10/11 64-bit | Same            |
| **CPU**     | 2-core, 1.5 GHz               | 4-core, 2.5 GHz |
| **RAM**     | 8 GB                          | 16 GB           |
| **Disk**    | 2 GB                          | 4 GB            |
| **Display** | 1280x800                      | 1920x1080       |

Nine. is distributed as an **AppImage** on Linux (no installation required) and a **self-contained, portable .exe** on Windows. Nine is tested on RHEL 10 with GNOME; see [AppImage Requirements](https://github.com/xnodeoncode/Nine/blob/main/Documentation/Quick-Start-Guide.md#appimage-requirements) for what your Linux system needs to provide.

## Application Limits

Nine. is intentionally constrained for an optimal user experience:

| Items             | Limit                          | Reason                                |
| ----------------- | ------------------------------ | ------------------------------------- |
| **Properties**    | Maximum 9                      | Focused workflows — it's our identity |
| **Users**         | Maximum 4 (1 system + 3 login) | Simplified access control             |
| **Organizations** | 1                              | Desktop application scope             |
| **File uploads**  | 10 MB per file                 | Performance management                |

## Technology Stack

- **Framework:** ASP.NET Core 10.0 + Blazor Server
- **Desktop:** ElectronNET.Core 0.4.1
- **Database:** SQLite with SQLCipher AES-256 encryption
- **PDF Generation:** QuestPDF, used under its own license (not Nine's MIT license) — see [Third-Party Licenses](#third-party-licenses)
- **UI:** Bootstrap 5.3, Bootstrap Icons
